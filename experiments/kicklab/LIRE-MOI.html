VERSION 0.6.1 / WINDOWS PORTABLE

KICK / LAB

Cette version repart de la base audio stable et applique la disposition Maschine+ demandée : deux écrans KICK, huit knobs, huit groupes A–H, modes Pad/Keyboard/Step et commandes physiques. Souris et clavier restent toujours utilisables sans contrôleur.

Test musical conseillé

  1. Extraire tout le ZIP puis ouvrir KickLab.exe. Le dossier demo-kit doit rester à côté.
  2. Le groupe A contient le kit de démonstration. Les groupes B–H sont vides et peuvent recevoir chacun seize autres WAV.
  3. Utiliser PAD MODE pour les one-shots, KEYBOARD pour jouer le sample sélectionné à différentes hauteurs, ou STEP pour éditer les pas 1–16.
  4. Dans Step, maintenir Select ou Shift puis frapper un pad pour choisir la piste.
  5. Ouvrir 4 Sequences. Pendant Play, un pad met la séquence choisie en attente jusqu'à la fin de la boucle courante.
  6. Ouvrir 8 Songs, choisir une séquence avec les pads, régler ses répétitions avec P2, cliquer sur Ajouter, puis Lire.
  7. Tester PLUG-IN / Instance, Program Edit et MIDI Control. Enregistrer depuis FILE, puis rouvrir le projet pour vérifier les huit groupes.

Banque actuelle

Filter, Saturation, Dynamics, Ambience, Reverb, Distortion, EQ, Modulation, Delay et Lo-Fi. Les nouveaux processeurs sont Baxandall2, Biquad2, Pressure5, Pop2, AutoPan, ChorusEnsemble, PurestEcho, TapeDelay2, Chamber2, Galactic, DeRez2 et BitGlitter.

Les valeurs et noms de paramètres viennent des sources Airwindows de 0700-AAM. L'interface Windows remplace les commandes de la surface matérielle qui n'existe pas encore sur PC.

Clavier et MIDI

Les pads répondent à A Z E R / Q S D F / W X C V / 1 2 3 4. MIDI Control peut apprendre les 16 knobs des deux pages, les 128 pads A–H, les touches Soft, les modes, le transport, les raccourcis, la rotation 4D et Retour/Escape. La rotation est apprise en relatif 1/127 pour fonctionner dans les deux sens. Le profil KICKMIDI 4 reste compatible avec les profils 1–3. Le dernier port MIDI est reconnecté au lancement ; les anciens profils peuvent être récupérés depuis SETTINGS → Importer un ancien profil MIDI.

Projets et limites

Les nouveaux fichiers utilisent KICKLAB 6 et conservent les huit groupes. Les versions 1 à 5 restent lisibles. Les WAV restent référencés par leur chemin et ne sont pas intégrés au projet.

Le Keygroup actuel est monophonique et Chords reste réservé. Song n'a pas encore l'automation Track Mute. Sortie Windows WinMM stéréo 48 kHz ; pas encore d'ASIO, de VST3 ni de synthétiseurs KICK. La Factory Sample Library est volontairement vide.
