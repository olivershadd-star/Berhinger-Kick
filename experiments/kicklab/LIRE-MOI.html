VERSION 0.17.0 / WINDOWS PORTABLE

KICK / LAB

Cette version repart de la base audio stable et applique la disposition Maschine+ demandée : deux écrans KICK, huit knobs, huit groupes A–H, modes Pad/Keyboard/Step et commandes physiques. Souris et clavier restent toujours utilisables sans contrôleur.

Test musical conseillé

  1. Extraire tout le ZIP puis ouvrir KickLab.exe. Le dossier demo-kit doit rester à côté.
  2. Le pattern A référence le Drum Program A et son kit de démonstration. B–H sont huit autres patterns, initialement reliés à des Programs vides.
  3. Utiliser PAD MODE pour les one-shots. Le dernier pad joué devient automatiquement la piste lorsque STEP est activé. Depuis KEYBOARD, jouer une hauteur puis passer sur STEP permet de séquencer cette note sur les pas 1–16.
  4. Dans Step, maintenir Select ou Shift puis frapper un pad pour choisir la piste.
  5. Appuyer sur EVENTS, choisir un step avec les pads, puis régler Velocity, Probability, Ratchet et Length avec P1–P4. L'encodeur 4D et gauche/droite changent de step dans les deux sens.
  6. Ouvrir List Edit dans le menu 9 ou avec Shift + EVENTS. L'écran A parcourt Time et Pad/Note ; l'écran B édite Length, Velocity, Probability et Ratchet. Précédent/Suivant/Insérer/Supprimer sont disponibles au-dessus de l'écran A.
  7. Ouvrir 4 Sequences. Pendant Play, un pad met la séquence choisie en attente jusqu'à la fin de la boucle courante.
  8. Ouvrir 8 Songs, choisir une séquence avec les pads, régler ses répétitions avec P2, cliquer sur Ajouter, puis Lire.
  9. PLUG-IN / Instance ouvre les seize Programs : assigner, créer ou dupliquer un kit sans copier les steps. PITCH / PAD EDIT expose ensuite Sample, ADSR, Loop Sync, Drum et Layers : quatre couches, vélocité, Cycle/Random, Choke et Reverse.
  10. Ouvrir MIXER pour les pistes du pattern. Utiliser Shift + MIXER pour le Pad Mixer du Program : Level/Pan sur les seize pads, répartis en deux pages physiques. Shift + MUTE ouvre les Pad Mutes ; un groupe Choke/mute suit ensemble.

Banque actuelle

Filter, Saturation, Dynamics, Ambience, Reverb, Distortion, EQ, Modulation, Delay et Lo-Fi. Les nouveaux processeurs sont Baxandall2, Biquad2, Pressure5, Pop2, AutoPan, ChorusEnsemble, PurestEcho, TapeDelay2, Chamber2, Galactic, DeRez2 et BitGlitter.

Les valeurs et noms de paramètres viennent des sources Airwindows de 0700-AAM. L'interface Windows remplace les commandes de la surface matérielle qui n'existe pas encore sur PC.

Clavier et MIDI

Les pads répondent à A Z E R / Q S D F / W X C V / 1 2 3 4. MIDI Control peut apprendre les 16 knobs, les 128 pads A–H et les seize touches Soft distinctes des deux pages. Le profil KICKMIDI 5 relit les profils 1–4 et est enregistré visiblement dans profiles/MaschinePlus.kickmidi, à côté de l'exécutable. Utiliser SAVE MIDI ou SETTINGS → Sauvegarder le profil MIDI maintenant.

Loops, tempo et performance

Pad Edit → Loop Sync mémorise le BPM source et adapte la vitesse du loop au tempo courant. Le bouton TEMPO ouvre les réglages ±10, ±1 et ±0,1 BPM. NOTE REPEAT / Arp utilise l'horloge audio ; FOLLOW choisit 1/4, 1/8 ou 1/16. Chords joue des triades arpégées.

Programs, bibliothèque, kits et projets

Un Program contient les seize pads, jusqu'à quatre WAV par pad et son Pad Mixer ; un Pattern contient les événements et référence un Program. Plusieurs patterns peuvent partager un Program, tandis que Duplicate copie les événements sans remplacer le Program de destination.

Le dossier externe samples accepte catégories, packs et sous-dossiers. Le dossier kits/User reçoit les fichiers légers .kickkit. Sauvegarder/Charger un kit agit sur le Program actif, jamais sur ses patterns.

Les nouveaux projets utilisent KICKLAB 13 et les kits KICKKIT 3. KICKLAB 1–12 et KICKKIT 1–2 restent lisibles. L'export WAV rend le pattern actif avec son Program en stéréo 48 kHz / 24 bits. Loop Sync modifie actuellement la vitesse et donc la hauteur ; le time-stretch spectral reste à porter. Sortie Windows WinMM ; pas encore d'ASIO ni de VST3.
