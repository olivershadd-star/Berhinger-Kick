PROFIL MIDI PORTABLE KICK LAB

KICK Lab crée et met à jour dans ce dossier le fichier :

    MaschinePlus.kickmidi

Ce fichier contient les affectations MIDI apprises. Conservez ou copiez le
dossier profiles avec KickLab.exe pour retrouver le mapping dans une nouvelle
version portable.

La commande SETTINGS > Sauvegarder le profil MIDI maintenant force l'écriture.
La touche contextuelle SAVE MIDI de la page MIDI Control fait la même chose.
